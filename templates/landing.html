Architecture

Multi-Signal Evaluation Pipeline

HalluciBench does not rely on a single superficial score. Every model output is analyzed through five distinct evaluator layers to quantify hallucination risk and pinpoint specific failure modes.

Exact Match & Substring Alignment

Normalizes text to verify exact factual matches against verified reference answers.

Semantic Similarity Vector distance

Calculates token overlap Jaccard distance and sequence ratio alignment.

Factuality & Abstention Accuracy

Verifies numbers, entities, dates, and tests if models properly abstain when data is insufficient.

Citation Verification

Detects fabricated URLs, non-existent references, and unsupported source claims.

Error Taxonomy Categorization

Model failures are classified into actionable research labels:

Fabricated Fact Incorrect Fact Contradiction Unsupported Claim Wrong Calculation Misinterpretation Citation Error Failure to Abstain Overconfident Answer
