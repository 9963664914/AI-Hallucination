HalluciBench Evaluation Methodology

Comprehensive breakdown of metrics, scoring formulas, evaluator design, and research limitations.

1. What Hallucination Means in HalluciBench

In HalluciBench, an AI Hallucination is defined as any generated content in a model's response that is factually false, unverified by ground truth references, internally contradictory, or falsely asserted with high confidence on an unanswerable question.

Unlike simple grammar or syntax errors, hallucinations represent epistemic failures where the language model generates ungrounded assertions that appear plausible but are factually invalid.

2. Transparent Scoring Formulas

Metric Name Mathematical Formula Description & Target
Hallucination Rate (%) $$\text{Hallucination Rate} = \left( \frac{N_{\text{hallucinated}}}{N_{\text{total}}} \right) \times 100$$ Percentage of evaluated samples flagged as containing hallucinations. Lower is better.
Factual Accuracy (%) $$\text{Factual Accuracy} = 100 - \text{Hallucination Rate}$$ Percentage of answers aligned with trusted ground truth reference answers. Higher is better.
Abstention Accuracy (%) $$\text{Abstention Acc} = \left( \frac{N_{\text{correct\_abstentions}}}{N_{\text{unanswerable}}} \right) \times 100$$ Accuracy of the model in declining to answer or stating insufficient context on unanswerable questions.
Semantic Similarity $$\text{Sim} = 0.5 \times \text{Jaccard Token Overlap} + 0.5 \times \text{Sequence Ratio}$$ Hybrid n-gram and token distance string matching metric. Range [0.0 - 1.0].
Composite Score $$\text{Score} = 0.20 S_{\text{exact}} + 0.35 S_{\text{semantic}} + 0.35 S_{\text{fact}} + 0.10 S_{\text{cite}}$$ Weighted multi-signal evaluation score across exact, semantic, factual, and citation signals.

4. Important Disclaimers & Limitations

Evaluation Estimate Notice: Hallucination detection scores generated by HalluciBench are empirical evaluation estimates based on static reference answers and automated string/semantic matchers. They do not constitute absolute mathematical proof that an answer is true or false in every possible real-world context.
  • Static Reference Answers: Reference answers represent ground-truth facts as of dataset creation dates. Current-events questions are marked explicitly with date context.
  • Paraphrasing Variability: Valid model answers that use unexpected synonyms or creative phrasing may occasionally receive lower semantic overlap scores.
  • Extensibility: Additional evaluators (such as LLM-as-a-judge or exact embedding distance adapters) can be added via the BaseEvaluator interface.
